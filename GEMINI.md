# Правила проекта «Личный помощник» (HelpTool)

1. **Каждый патч на GitHub.** После любого завершённого и проверенного изменения (интерфейс, функции, исправления) обязательно:
   - Проверь, что рабочие и личные файлы (`.env`, `assistant.db*`, `webview-data/`, `tunnel.json`, `bot.log`, `bot.pid`, `bin/node.exe`, `bin/cloudflared.exe`) не отслеживаются Git и не содержат утечек ключей.
   - Сделай понятный коммит с описанием патча и сразу отправь его на GitHub (`git push origin main` в `masturbek-lgbtq/HelpTool`).
2. **Синхронизация сборки для друга.** После изменений в приложении обновляй чистую папку `..\Помощник (Для друга)` и архив `..\Помощник-Для-Друга.zip`, сохраняя отсутствие личных данных и ключей (и при значимых версиях предлагай обновить релиз на GitHub через `gh release`).
3. **Не трогай 16 аниме-тем без запроса.** При любых переделках сохраняй каталог тем и их персонализированные реплики.
