# Личный помощник

Настольное приложение для Windows (`Помощник.exe`) и Telegram-бот с единой локальной базой, Bento-интерфейсом и 16 темами оформления.

## Возможности
- **Обзор дня** — сводка расписания на сегодня, дневных дел, главных общих планов, привычек и чтения на одном экране.
- **Общие планы** — долгосрочные цели по категориям (`Учёба`, `Проекты`, `Личное`), приоритет ★ и перенос шага на сегодня в один клик.
- **База привычек** — отметки и числовые цели с расчётом серий и таблицей прогресса за 14 дней.
- **Книги** — полка чтения со статусами (`В планах`, `Читаю сейчас`, `Прочитано`), заметками и оценкой.
- **Анимации, интерактив и автообновление (`↻`)** — живые фоны, мини-персонажи для каждой темы, таймер фокуса на 25 минут, отключаемые звуки интерфейса и безопасное обновление напрямую с GitHub с резервной копией базы.

## Безопасность
- Токен Telegram-бота и ключ Gemini шифруются локально через Windows DPAPI с привязкой к учётной записи Windows.
- База записей `assistant.db`, ключи, кэш окна, резервные копии и логи исключены из репозитория.

## Запуск
1. **Windows:** для готовой сборки просто откройте **`Помощник.exe`**. При запуске из исходников скопируйте `.env.example` в `.env` (или оставьте пустым — приложение сразу работает автономно) и положите `node.exe` в `bin\node.exe` (для мини-приложения в Telegram также `cloudflared.exe` в `bin\cloudflared.exe`).
2. **Версия для друзей (Windows, без школы):** готовый архив доступен в разделе [Releases](https://github.com/masturbek-lgbtq/HelpTool/releases).

## Версия для iPhone (без App Store и без сервера)
Отдельная автономная версия без школьного раздела доступна по ссылке:
**https://masturbek-lgbtq.github.io/HelpTool/**

1. Откройте ссылку на iPhone в **Safari**.
2. Нажмите **«Поделиться»** внизу экрана и выберите **«На экран „Домой“»**.
3. Запускайте помощник по иконке с рабочего стола как обычное приложение: база хранится локально на телефоне, работает без интернета, поддерживает добавление задач в «Календарь» iPhone, резервные копии в «Файлы» и защиту по 4-значному PIN-коду с шифрованием записей.
