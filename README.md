# Личный помощник 3.0

Настольное приложение для Windows (`Помощник.exe`), версия для iPhone и Telegram-бот с единой локальной базой, Bento-интерфейсом, конструктором тем и гибкой настройкой разделов под учёбу, работу или личные проекты.

## Возможности 3.0
- **Обзор дня** — сводка расписания или рабочего графика на сегодня, дневных задач, общих планов, привычек и чтения на одном экране.
- **Профили жизни и конструктор разделов (`✦ Разделы`)** — быстрый выбор режима («Учёба», «Работа и проекты», «Свободный режим»), переименование или скрытие любого раздела (например, замена «Школы» на «Рабочий график и созвоны») и создание своих категорий («Работа», «Фриланс», «Домашка», «Спорт», «Клиенты») для задач и планов.
- **Конструктор тем, 25 тем и детальные персонажи** — возможность создать свою тему (со своим фоном, автоподбором палитры, выбором частиц, персонажа и реплик), изменить или удалить любую существующую тему и в любой момент вернуть стандартный набор. Все 25 мини-персонажей прорисованы с высокой детализацией и живой анимацией.
- **Общие планы и дневные задачи** — задачи по датам и долгосрочные цели по вашим категориям, приоритет ★ и перенос шага на сегодня в один клик.
- **База привычек** — отметки и числовые цели с расчётом серий и таблицей прогресса за 14 дней.
- **Книги и коллекции** — полка со статусами (`В планах`, `Читаю сейчас`, `Прочитано`), заметками и оценкой.
- **Анимации, интерактив и автообновление (`↻`)** — живое дыхание персонажей, искры при закрытии задач, таймер фокуса на 25 минут, отключаемые звуки интерфейса и безопасное обновление напрямую с GitHub с резервной копией базы.

## Безопасность
- Токен Telegram-бота и ключ Gemini шифруются локально через Windows DPAPI с привязкой к учётной записи Windows.
- База записей `assistant.db`, ключи, кэш окна, резервные копии и логи исключены из репозитория.

## Запуск
1. **Windows:** для готовой сборки просто откройте **`Помощник.exe`**. При запуске из исходников скопируйте `.env.example` в `.env` (или оставьте пустым — приложение сразу работает автономно) и положите `node.exe` в `bin\node.exe` (для мини-приложения в Telegram также `cloudflared.exe` в `bin\cloudflared.exe`).
2. **Версия для друзей (Windows, без школы):** готовый архив доступен в разделе [Releases](https://github.com/masturbek-lgbtq/HelpTool/releases).

## Версия для iPhone 3.0 (без App Store и без сервера)
Отдельная автономная версия с профилями, конструктором тем, 25 темами и детальными персонажами — база хранится локально на телефоне, работает без интернета, поддерживает добавление задач в «Календарь» iPhone, резервные копии в «Файлы» и защиту по 4-значному PIN-коду с шифрованием записей.

- **Способ 1 (скачать установочный файл):** откройте отдельный релиз [Версия для iPhone 3.0](https://github.com/masturbek-lgbtq/HelpTool/releases/tag/iphone-v3.0) на iPhone в **Safari**, скачайте **`HelpTool-iPhone.mobileconfig`** («Разрешить»), затем откройте **Настройки → Профиль загружен → Установить**. Иконка «Помощник» сразу появится на рабочем столе.
- **Способ 2 (прямая ссылка):** откройте https://masturbek-lgbtq.github.io/HelpTool/ в **Safari**, нажмите **«Поделиться» → «На экран „Домой“»**.
