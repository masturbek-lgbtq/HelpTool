# Личный помощник

Настольное приложение для Windows (`Помощник.exe`) и Telegram-бот с единой базой данных, минималистичным Bento-интерфейсом и 16 аниме-темами.

## Разделы

- **Обзор дня** — сводка в Bento-сетке: расписание, дневные задания, главные общие планы, привычки и текущая книга.
- **Школьное расписание** — цикл 1 или 2 недели, кабинеты, онлайн-ссылки, быстрая отмена урока на сегодня, загрузка списком или по фото (через Gemini), уведомления до начала урока и режим паузы.
- **Дневные задания** — дела по датам и времени напоминания, с переносом невыполненных прошлых задач на сегодня.
- **Общие планы** — глобальные долгосрочные задачи с категориями (`Учёба`, `Проекты`, `Личное`), отметкой «Важное ★» и кнопкой «На сегодня».
- **База привычек** — галочки и числовые цели, дни недели, серии и таблица за 14 дней.
- **Книги** — база чтения со статусами (`В планах`, `Читаю сейчас`, `Прочитано`), заметками/прогрессом и оценкой.

## Безопасность

- Все ключи (`bot_token`, `gemini_api_key`) шифруются через Windows DPAPI с привязкой к текущему пользователю Windows.
- Файлы `.env`, `assistant.db*`, кеш WebView2 и логи исключены через `.gitignore`.

## Запуск

1. Скопируйте `.env.example` в `.env` (или оставьте пустым — приложение сразу работает локально).
2. Запустите `Помощник.exe` (для автономного запуска без установленного Node.js положите `node.exe` в `bin\node.exe`, для удалённого экрана Telegram Mini App положите `cloudflared.exe` в `bin\cloudflared.exe`).
